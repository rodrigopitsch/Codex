# NEXUS — Caçadas Entre Mundos

Apresentação temática construída sobre a mecânica do **Arquivo 13**, preservando plataforma 2D, progressão, checkpoints, pistas/objetivos, combate e chefes.

Antes de cada fase, o jogador escolhe um universo temático:

- Sobrenatural
- Attack on Titan
- Jujutsu Kaisen
- Demon Slayer

A escolha altera identidade visual, narrativa, missão e chefe, mantendo a mesma curva de controle e evolução do jogo-base.

## Estrutura

Este projeto fica isolado em `nexus-cacadas/` dentro do repositório de jogos e não possui qualquer dependência do projeto `monitoramento-avancado` da Vercel.

## Observação

Projeto de fã para demonstração. Não utiliza artes, logotipos, músicas ou outros arquivos oficiais das séries; nomes e marcas pertencem aos respectivos titulares.
